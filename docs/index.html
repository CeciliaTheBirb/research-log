本轮一起启用，尚未单独消融
01

历史噪声与部署匹配

辅助 forward 损失中，anchor 和首个生成块保持 clean；后续 GT 历史使用：

history = 0.375 × GT + 0.625 × ε
source time = 0.625, target time = 0

条件、负条件、有限差分分支共享同一历史噪声。这匹配噪声级别与时间条件；辅助目标仍使用加噪 GT 历史，并不等于完整 student 生成历史。

02

fake 与 DMD 的时间分布一致

两者先独立抽取 uniform 时间，再按 shift=5 转换：

u ∼ Uniform(0, 1)
σ = 5u / (1 + 4u)

统一的是抽样分布，不是每次强制使用相同的时间或噪声。teacher 权重保持冻结，rollout 时间网格保持不变。

共同的数据、损失与优化设置 +
模型 / 可训练参数
Cosmos3-Edge，28 层、hidden 2048。student / fake 的 LoRA rank=128、alpha=128、dropout=0；包含 student source / target time LoRA。底座与完整动作头冻结，real score 冻结。
数据
4775 条训练 clip；cached Cosmos latent＋车辆动作＋SFT caption。832×480，20 FPS，121 帧；caption 上限 2048 tokens，文本 dropout 10%。训练使用 cached latent，TinyVAE 只用于推理解码。
student 目标
L_student = L_forward + 2 × L_DMD，DMD 内部使用 0.5×MSE 约定。forward 保留 AnyFlow boundary / transition 辅助项，仍抽连续时间对 t≥r，50% 概率 r=0；有限差分 ε=0.005。
fake / guidance
student / fake 按 1:1 交替。fake 阶段重新执行无梯度 rollout，训练 flow-matching 目标 noise−endpoint。rollout CFG=1，real score CFG=4，fake 使用 conditional 查询。
反向传播
使用完整固定 422… rollout；每块全部 denoise 步反传，跨块历史 KV detach。未加入混合短轨迹训练、最后一步反传或独立的 4222 initialization warmup。
优化器 / 数值
AdamW，student / fake 学习率 2×10⁻⁶，β=(0, 0.999)，ε=10⁻⁸，weight decay=0，grad clip=1；固定学习率。模型 BF16，rollout 状态积分及损失 FP32；activation checkpointing 开启。
停止与保存
达到各自更新预算后停止；每 100 步验证及保存。当前比较 live student，未使用 EMA 或 FVD early stopping，不能把达到预算等同于已收敛。

历史记忆
28 层各有 history projection，将窗口移出的 vision/action KV 折叠为 ReLU 特征的线性注意力状态；使用 spatial RoPE。推理保留 sink 1、最近 2 个历史块，并读取记忆。

文本条件
本表采用空文本的 image＋actions 条件。官方推荐传入结构化 prompt；无 caption 的结果不能代表官方结构化文本场景。
公平比较口径

该模型同时改变了训练窗口、历史记忆、步数、score 初始化和训练数据。此处比较完整 checkpoint 的效果，不能把差异单独归因于 Hybrid Forcing。

评测协议与可比性说明 +

01 质量口径

172 条与两版 4222 训练集 session 分离的 validation。4775 条 train 与其 CID、session UUID、目录交集均为 0。这些验证视频已用于实验选择，属于 validation。HF hybrid 的训练集标注为 clips1k，与这 172 条的重叠尚未核实。

FVD 使用 I3D Kinetics400 特征，报告完整 121 帧与均匀 16 帧两种协议；完整 FVD 包含首帧。LPIPS-Alex、PSNR、SSIM 比较未压缩生成 RGB 与原始相机 RGB，排除首帧。

02 GPU 与可比性

旧学生和 HF hybrid 的质量评测使用 RTX A5000；两版 4222 使用 RTX A5000 / L40S 分片。底层 FP32 初始噪声固定并核对校验值；I3D 参考特征采用固定基准并核验跨 GPU 数值漂移。

FPS 按 L40S / RTX A5000 型号分别预热重复测量；hybrid 是新增的一轮单卡作业。未完成的硬件项标为排队，不使用质量分片耗时或其他型号估算。

03 FPS 口径

FPS = 360 个新帧 ÷ 三条视频各自中位总耗时之和。每片段、每模型、每模式预热 1 次后计时 3 次，并同步 GPU。

包含 rollout 与 TinyVAE BF16 流式解码。排除模型加载、cached 首帧编码、CPU 转换、写 MP4 和指标计算。每次生成都重建文本缓存。

04 条件与解释边界

旧模型使用原生 NavWorldGym、发布的固定 action prompt；两版 4222 与 HF hybrid 使用空 SFT 文本，不读取整段视频的未来 caption。各模型保留自己的原生数值路径。

旧学生和 hybrid 接收 120 行真实动作；两版 4222 checkpoint 沿用训练时 121 行含 anchor 占位的格式。训练长度、数据、窗口、score 初始化、并行规模和目标修改也不同，因此不能将排名仅归因于步数、KV 策略或历史记忆。

查看其余验证范围与后续工作 +

新模型三条加速验证视频的 latent / RGB 一致性检查通过；没有在本次部署加速后重新计算全 172 条 FVD。表中质量来自已完成的全量评测，吞吐来自新的单卡测试。

数据审计不证明历史 Stage 2、teacher 或旧学生的预训练未见过这些场景，也未完成视觉近重复或地理重叠检索。Noisy 两处目标修改和训练并行规模同时变化，尚需单项消融。FVD、配对画质指标及速度共同描述当前进展，不构成全部世界模型能力的结论。

后续可继续评估 120 行动作约定重训、两处 noisy 目标的独立消融，以及更长 rollout 和独立保留测试集。

03 / FINDINGS

当前发现

  1. Noisy KV 的1:5更新频率未显示整体收益。

    相同800次student更新预算，FVD121为221.91（1:1为215.35），配对差值区间跨0；LPIPS、PSNR、SSIM略差，FVD16略好。同作业A5000速度为25.76→25.73 FPS。暂保留1:1作为基线，不能仅凭增加fake更新次数认定critic滞后已经解决，或将结果推广到完整DMD2。

  2. 新增 HF hybrid 的完整 checkpoint 比较。

    172 条相同验证视频上，FVD121=269.73、FVD16=304.23，LPIPS=0.4454、PSNR=16.04 dB、SSIM=0.5185；A5000 为 20.11 FPS。SSIM 均值为四模型最高，但 FVD 和 LPIPS 均差于原三模型。采用原生 4,3,2,2,… 与 sink1/history2＋历史记忆；这里使用空文本，官方示例使用结构化 prompt。其训练数据、窗口和初始化也不同，结果不构成记忆模块的独立消融。

  3. Hybrid 的窗口与历史记忆已核查。

    sink1/history2、absolute RoPE、记忆读取和4322…步数与官方默认一致。默认路径重跑后RGB与原评测完全一致；抽查第0、13、27层，63次具有移出历史的读取均有非零贡献。关闭记忆后贡献为0。

  4. 旧学生后半段画质下降与撞墙，新模型有所改善。

    在本页对比样例中，尤其是雨后路口，旧 stage3 student 随 rollout 推进，后半段画质下降，并出现镜头撞向墙体的现象。新训练的 4222 clean 与 4222+noisy kv reuse 后半段画面相对稳定，撞墙问题也有所缓解。这是当前展示片段中的定性观察。

  5. 原三模型比较中，4222 clean 的 FVD 点估计最低。

    FVD121 为 202.08，比旧 stage3 student 的 231.96 低 29.88（约 12.9%）。配对 bootstrap 95% 差值区间为 [−54.83, −9.27]。LPIPS、PSNR、SSIM 与旧模型接近，FVD 排名不能代表全部视觉维度。

  6. 原三模型比较中，4222+noisy kv reuse 的配对画质指标最好。

    LPIPS=0.4150、PSNR=16.15 dB、SSIM=0.5142，在原三模型比较中均值最好。FVD121=215.35，相对旧模型的差值区间 [−37.87, +1.82] 跨 0。

  7. 更少的模型调用，已转化为实际吞吐收益。

    每个 6 秒 clip 的模型调用从旧模型 51 次降至 clean 的 33 次、noisy 的 24 次。两种 GPU 的实际 FPS 见上表；不按调用数比例推算硬件速度。

  8. 这轮比较仍有需要拆开的变量。

    两版新模型训练长度不同；noisy 同时加入历史噪声匹配和 score 时间分布统一，并改变了 SP 规模。现有新 checkpoint 仍使用 121 行含 anchor 占位的动作约定，旧模型使用 120 行真实转移。不能将全部差异单独归因于 4222 或 noisy KV。
